# Mobile brand source assets

master-mark-v2-1024.png is the approved raster master mark supplied for this release. `app-icon-foreground.png` is the supplied accent layer; keep it as a source asset rather than replacing the full master mark in an adaptive icon. The SVGs are code-native reference artwork.

The Expo runtime references generated PNG files under assets/images/. `launch-splash.png` is the supplied in-app launch visual, while `android-icon-monochrome.png` is the supplied themed-icon mask. The approved mark has been exported to the app icon, Android adaptive icon layers, favicon, and splash assets. Do not mix the old blue M mark with the book-and-check mark.
