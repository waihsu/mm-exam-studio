# MM Exam Studio User App

## Dev

```bash
bun install
bun run dev
```

## Build

```bash
bun run build
```

## Env

- `VITE_SERVER_URL`
- `VITE_APP_URL`

## Main Flows

- Practice
- Question paper builder
- Question swap / replace / reorder
- Finalize and PDF export
- Branding
- Subscription request with transaction ID and payment proof
