# MM Exam Studio Admin App

## Dev

```bash
bun install
bun run dev
```

## Build

```bash
bun run build
```

## Env

- `VITE_SERVER_URL`
- `VITE_APP_URL`

## Main Flows

- Admin auth
- Taxonomy CRUD
- Question bank CRUD and review
- Publish workflow
- Subscription approval queue
- User, content, support, and workspace administration
